# 🎓 Educational Data Insight Using Pig and Live Integration

## 📘 Overview
This project analyzes educational data using **Apache Pig** and integrates live data using **Sqoop** from **MySQL** to **HDFS** and back.

## 🧰 Technologies Used
- Apache Hadoop  
- Apache Pig  
- Apache Sqoop  
- MySQL Database
